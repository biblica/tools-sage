# BIC workflow controller

BIC operates only through generated SAGE tasks and governed controller commands. The canonical order is:

```text
workspace preparation
→ INSPECT task and committed submission
→ optional human memory-review provenance
→ REWRITE task
→ material-risk detection
→ conditional bounded OL mitigation only when risk level 2+ has a substantive trigger
→ concise translation-challenge ledger and report
→ urgency 0–3 logged and carried forward automatically
→ urgency 4 recommended candidate completed with a concise critical review item
→ isolated SELF-CHECK task
→ transactional target commit
→ optional immutable publication
```

Use one bounded scope and three distinct BIC roles: SOURCE (`CONTENT_SOURCE`), DONOR (`LEXICAL_DONOR`), and TARGET (`GENERATED_TARGET`). SOURCE is sole content authority; DONOR is vocabulary evidence only; TARGET remains a destination. SELF-CHECK receives the sealed REWRITE candidate as the object under check, not pre-existing TARGET Scripture. Use only conditional passage-relevant Greek or Hebrew evidence opened by the REWRITE risk rule. Do not combine stages in one governed task context.

INSPECT proposes challenges and memory records but does not write target Scripture. A human memory-review receipt is optional provenance and does not authorise progression or promote a proposed memory record to `APPROVED_FOR_USE`. REWRITE receives only governed evidence routed by the task. SELF-CHECK receives the sealed staged candidate, the material challenge ledger, but no first-pass rationale.

Completion is determined by SAGE state and successful submission, not by file presence or a model statement.

## Governed risk and reporting rule

REWRITE completes whenever a structurally valid evidence-supported candidate can be produced. Only material translation challenges are listed individually; lower-level and automatically resolved matters are aggregated. Linguistic uncertainty is reported with urgency rather than converted to `BLOCKED`. Urgency 3 never interrupts flow. Urgency 4 never interrupts REWRITE and never opens an Operator candidate-selection prompt; it produces a concise critical report and proceeds to SELF-CHECK.
