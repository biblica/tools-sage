# SAGE Portable Bundle

This directory is the movable SAGE bundle:

- `sage` / `sage.cmd` — Operator launchers
- `app/` — immutable application files
- `localdata/` — persistent `inputs/`, `work/`, `reports/`, exports, settings, and managed Python runtime

Run `./sage` on macOS/Linux or `sage.cmd` on Windows. Application documentation is
available in [`app/README.md`](app/README.md) and [`app/docs/INDEX.md`](app/docs/INDEX.md).
