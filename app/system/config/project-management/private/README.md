# Private Project-Management Material

This repository is public. Everything in this folder except this README is ignored by Git
(`.gitignore`) and stays on the maintainer's machine.

Put here what the ledger needs to point to but the public repository must not carry:

- release-gate receipts and analysis notes that are not cleared for publication;
- tester and user feedback;
- anything that quotes WIP text, NIV text beyond the fair-use limit, or other licensed material.

Public records ([TODO](../TODO.md), [Implemented Updates](../IMPLEMENTED-UPDATES.md), release docs)
may name a file here by path, but must summarize it without quoting its private content.
