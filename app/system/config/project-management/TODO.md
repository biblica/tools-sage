### BIC Skill and prompt review (milestone `MS-REVIEW-20261022`)

Source: read-only review of 2026-10-22 of the three BIC Skills (`bic-inspect`, `bic-rewrite`,
`bic-self-check`), their references, both pinned BIC contracts, and the prompt SAGE builds for each BIC
stage. Scope is BIC only. The standing rules of the 2026-10-13 plan apply.

What a BIC model receives: the fixed preamble, the ACT Process brief (`act_render.py`), the two pinned
protected contracts (REWRITE, SELF-CHECK, and the OL micro step only), the read-class rules, and the
routed evidence (SOURCE packet, DONOR vocabulary, INSPECT record and memory, semantic packets, grammar
contracts). `SKILL.md` and every `references/` file are governance inputs: hashed and listed as
controller-only (`act_tasks.py:1871`), never rendered into the prompt (`llm_tasks.py:2145-2159`). The
provider request carries only the prompt and the output schema (`executors/base.py` `ProviderRequest`),
and Codex runs in an empty temporary directory with the prompt on stdin (`executors/codex_cli.py`).

Findings:

- **A. Non-protected BIC text** (may be streamlined under the 2026-10-13 rule).
  - The Skills hold instructions the model needs but never receives. SELF-CHECK: the brief says only
    "Correct only supported fidelity, USFM, project-grammar, or governed candidate-decision issues"; the
    independent checklist is in the Skill alone. INSPECT: reading semantic packets first, separating
    observed evidence, inference, and uncertainty, and proposing memory only for reusable decisions are
    in the Skill alone.
  - REWRITE brief steps 6-7 tell the model to run the OL check; SAGE runs it as a separate micro step.
  - The Skills tell a model to "read every listed Skill reference", which no model sees. Several
    references describe controller work only (`BIC-WORKFLOW-CONTROLLER.md`,
    `MEMORY-AND-OPERATOR-BOUNDARY.md`, `PROJECT-GRAMMAR-AND-RTC-STC.md`); the BIC copies of
    `LOCAL-EVIDENCE-AND-LINGUISTIC-COMPETENCE.md` have drifted from the global file;
    `REWRITE-RISK-AND-OL.md` sits in SELF-CHECK although it describes pass-1 work.
- **B. Protected contracts** (reach the model once, verbatim; any change is a deliberate re-pin).
  - Still needed: SOURCE as complete authority, the prohibited transformations (stronger models know
    familiar Bible wording better and drift toward it), the USFM integrity rules, and the SELF-CHECK
    requirement.
  - Possibly redundant: the five-part lexical-burden score. Longman bands are never routed, so
    familiarity (40%) is always `UNKNOWN` or a model estimate, and the total is only a tie-breaker.
  - Misplaced: about half of `bic-verb-selection-policy.yml` describes controller work
    (`calculation_owner: LOCAL_CONTROLLER`, reporting tiers, completion mapping).
  - Language-specific: the capitalization rule cites Indonesian `Dia`, `Ia`, `-Nya` in a contract that
    applies to every SOURCE.
  - The minimum-departure rule names naturalness only as a tie-break, which leans output literal.
- **C. BIC pipeline.**
  - INSPECT is a separate model call whose memory proposals reach REWRITE only after an Operator marks
    them `APPROVED_FOR_USE`.
  - BIC replaces existing TARGET text in scope verse by verse without reading it, and the Job wizard
    does not warn that a Paratext TARGET already has text there.
