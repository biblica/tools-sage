# Archived SAW Skills

These files preserve the former Skills and source prompts for historical comparison. They are not registered or routed into new tasks. Existing task manifests and qualification receipts retain their historical identities; they are not rewritten as RTC/STC evidence. A task whose recorded Skill path or hash no longer matches requires recreation.

Current ownership is `rtc`, `stc`, `rtc-focused-check`, and `rtc-original-language-review`. The latter two are parked RTC helpers, reachable only through the retained legacy bounded-operation plumbing. They are not RTC/STC menu operations. Shared rules are in `../global/references/`.
