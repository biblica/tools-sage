# Shared Skill references

These are process-control references, not an executable workflow or model route. RTC, STC, and the parked RTC helpers declare them in `system/config/skills.json` with exact hashes. The controller validates and routes those files in each sealed task.

Local content evidence, linguistic competence, index provenance, stream separation, and read-only analysis execution apply across these Skills. Each owning Skill still defines its own authority: RTC compares WIP with REFERENCE and conditionally adjudicates source questions; STC compares WIP directly with testament-correct original-language Scripture. Shared rules never give STC a Reference dependency or broaden RTC source access.

BIC retains its existing protected Skill contracts. NCA retains its specialized number extraction and correspondence contracts.
