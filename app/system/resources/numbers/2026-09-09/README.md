# Bundled NCA reference

This Core runtime package contains the authoritative numeric indexes, registered alternate readings, units, footnote guidance, mapping, and provenance supplied for NCA. Every retained reference file is byte-identical to the handover qualified during implementation and regression testing. Current SAGE code applies the subsequent interpretation, scope, bridge, and evidence refinements.

The runtime package has its own identity and complete checksum inventory. Original manifest, checksum inventory, and distribution notes remain under `provenance/`; these identify the source handover, not additional runtime inputs. Development instructions, source ZIPs, and the workbook are not required by the runtime and are omitted. Original verification status and lineage diagnostics remain explicit. SAGE reads this package without writing to Core.
