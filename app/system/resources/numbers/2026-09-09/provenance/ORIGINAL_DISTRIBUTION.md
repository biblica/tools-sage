# Provenance and Distribution

## Internal authority

For this configured SAGE reference:

1. supplied HEB/GRK corpus = Authority 1;
2. supplied NIV main text = Authority 2;
3. ancient witnesses, parallels, and scholarship = explanatory evidence.

## Critical-note provenance

Every researched numeric critical row resolves through `SOURCE_IDS` into `provenance_sources.tsv`. Runtime findings should preserve source IDs and may expose source URLs for operator review.

Do not manufacture new scholarship claims in runtime code. If a new target difference is not in the registry, classify it for review rather than extrapolating from another verse.

## Public redistribution caveat

The workbook records unresolved metadata for the supplied OL source bundles:

- Hebrew README identifies only a generic MT source.
- Greek README metadata is ambiguous between Nestle-Aland and AGNT.

The exact editions, acquisition sources, copyright status, and redistribution authority must be resolved before public distribution of the source-text bundles or a derivative that requires such permission.

This caveat does not change the configured internal authority order.

## NIV

Use the supplied NIV package according to the project's authorized/internal-use context. NUMBERS extraction uses **published main text** as comparator; NIV footnotes are research evidence for the variant registry, not Authority 1.
