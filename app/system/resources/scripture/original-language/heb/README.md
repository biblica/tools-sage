# @HEB bundled distribution resource

This directory contains the governed 39-book Hebrew Bible `.SFM` source distributed with SAGE.
SAGE treats these files as immutable USFM source and deterministically compiles only authorized
bounded coordinates to USJ for runtime comparison. If the corpus is absent or incomplete, Hebrew OL
capability is not READY and can be explicitly reconfigured.

Before public distribution, record the exact edition, acquisition source, and redistribution
authority. Current imported metadata names only a generic MT source, has an empty copyright field,
and declares a `hebRESa.SFM` suffix while the corpus filenames use `hebRES.SFM`.
