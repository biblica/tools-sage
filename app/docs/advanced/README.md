# Advanced SAGE Documentation

The `docs/` root contains short Operator instructions for normal setup and daily work. This
directory contains technical, governance, maintenance, and release material grouped by topic.

## Topics

- [Architecture](architecture/) — system structure, naming, output, cardinality, and terminology
  contracts.
- [Projects and Resources](projects-and-resources/) — Project lifecycle, profiles, versification,
  original-language resources, rights, and lexical/semantic resources.
- [Workflows](workflows/) — BIC/SAW execution, planning, remediation, recovery, and authority rules.
- [Models and AI](models-and-ai/) — provider selection, local AI, evidence boundaries, competency,
  and handoff optimization.
- [Maintenance](maintenance/) — [Python maintenance](maintenance/PYTHON-MAINTENANCE.md), hardening,
  audits, localization, and UI presentation contracts.
- [Release](release/) — gates, validation evidence, release notes, handover, and package inventory.
- [Future Work](future/) — explicitly non-current designs.

Start with the root [Documentation Index](../INDEX.md) if you are looking for an Operator guide.
