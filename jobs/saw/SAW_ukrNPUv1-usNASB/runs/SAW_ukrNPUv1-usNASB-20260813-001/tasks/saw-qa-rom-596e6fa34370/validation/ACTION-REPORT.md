## Actionable findings

### SAW-QA-ROM-1-5-001 — ROM 1:5

- Category: `MEANING`
- Action level: `CHANGE`
- Confidence: `HIGH`

**Issue:** «привести до послуху віри всі народи» makes all nations the direct object to be brought into obedience. The reference describes bringing about the obedience of faith among all the Gentiles, not an assertion that every nation is brought into that obedience.

**Required action:** Revise the clause so that «послух віри» is brought about among/all the nations, without making «всі народи» the direct object of «привести».

**Evidence IDs:** WIP, REFERENCE

### SAW-QA-ROM-1-11-001 — ROM 1:11

- Category: `MEANING`
- Action level: `CHANGE`
- Confidence: `HIGH`

**Issue:** «розділити з вами якийсь духовний дар» means to share a spiritual gift with the Romans. The reference states that Paul wants to impart a gift to them for their strengthening; the direction of the gift is lost.

**Required action:** Replace «розділити з вами» with wording that clearly conveys giving or imparting a spiritual gift to the Romans.

**Evidence IDs:** WIP, REFERENCE

### SAW-QA-ROM-1-27-001 — ROM 1:27

- Category: `TERMINOLOGY`
- Action level: `CHANGE`
- Confidence: `HIGH`

**Issue:** «належне покарання за свої збочення» renders the stated «error» as «perversions», adding a more specific and evaluative characterization than the reference expresses for the basis of the penalty.

**Required action:** Use a Ukrainian term corresponding to «error»/«wrongdoing» that does not add the specific characterization «збочення».

**Evidence IDs:** WIP, REFERENCE

### SAW-QA-ROM-1-29-001 — ROM 1:29

- Category: `MEANING`
- Action level: `CHANGE`
- Confidence: `HIGH`

**Issue:** The list has «розпусти» where the reference includes «evil». «Розпуста» introduces sexual debauchery, which is not the listed item in the reference, and the reference’s distinct item «evil» is consequently absent.

**Required action:** Revise the first list so its four items correspond to unrighteousness, wickedness, greed, and evil, without adding «розпуста».

**Evidence IDs:** WIP, REFERENCE
