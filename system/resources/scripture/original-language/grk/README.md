# @GRK bundled distribution resource

This directory contains the governed 27-book Greek NT `.SFM` source distributed with SAGE.
SAGE treats these files as immutable USFM source and deterministically compiles only authorized
bounded coordinates to USJ for runtime comparison. If the corpus is absent or incomplete, Greek OL
capability is not READY and can be explicitly reconfigured.

Before public distribution, record the exact edition, acquisition source, and redistribution
authority. Current imported metadata is ambiguous between Nestle-Aland and AGNT and has an empty
copyright field; SAGE must not guess the resolution.
