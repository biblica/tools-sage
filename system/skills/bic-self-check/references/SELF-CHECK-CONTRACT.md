# BIC SELF-CHECK contract

## Purpose

Independently review one exact `STAGED_VALIDATED` REWRITE candidate in a fresh isolated SAGE task context before target commit.

## Required evidence

Use the staged predecessor candidate, routed SOURCE, decontextualized DONOR vocabulary evidence, routed grammar contracts, task marker policy, applicable governed memory, and routed original-language evidence. Do not receive, request, or reconstruct the first-pass REWRITE rationale.

## Self-check controls

- Compare the staged candidate directly with the SOURCE, which remains the sole content authority.
- Correct additions, omissions, semantic shifts, wrong senses, referent errors, obscuring grammar, information-order errors, and protected-marker defects.
- Preserve exact scope, coordinate coverage, and protected semantic markers.
- Apply only layout-marker normalization permitted by the task marker policy.
- Submit a complete grammar assessment bound to the corrected candidate hash.
- Write only the outputs allowed by `ACT.md`.

## Commit boundary

SAGE commits only after scope, coordinate, protected-marker, grammar-assessment, hash, USFM, predecessor, and transaction validation pass. SAGE writes the target-owned filename transactionally. Do not edit the target project directly.
