# BIC REWRITE contract

## Purpose

Produce one complete bounded target USFM candidate after the exact INSPECT scope has been committed. Human memory review and provisional grammar review are reported as attention; neither is an execution prerequisite.

## Required evidence

Use only the routed SOURCE, decontextualized DONOR vocabulary packet, applicable `APPROVED_FOR_USE` memory, committed translation challenges, source and target grammar contracts, the task marker policy, and conditional original-language evidence only when the governed material-risk threshold opens it. SOURCE is the sole content authority. DONOR may support lexical choice only and must not supply wording, sequence, syntax, propositions, participant structure, or discourse. Do not use pre-existing TARGET Scripture, an unrouted translation, or reconstructed evidence from another task.

## Rewrite controls

- Represent every bounded source content unit in the target language.
- Preserve exact coordinate coverage and protected semantic USFM markers.
- Apply only layout-marker normalization permitted by the task marker policy.
- Apply memory only when its approved sense and conditions match the local evidence.
- During ordinary drafting, do not read conditional OL files. After the governed material-risk threshold and substantive trigger are met, the sealed transport may release one question-specific OL micro-scope per material challenge. Raw SOURCE and OL Scripture for that phase are restricted to one single verse; a `VERB_CHOICE` micro-check resolves only the disputed verb's verbal sense/function. Never broaden to surrounding Scripture automatically.
- Record all canonical machine findings in the persistent inter-task ledger, but list only material urgency 2–4 challenges individually in the human report; consolidate repeated causes and aggregate lower-level or automatically resolved matters.
- Record a complete rule-by-rule grammar assessment bound to the candidate hash.
- Write only the candidate and submission files allowed by `ACT.md`.

## Result

A valid submission creates `STAGED_VALIDATED` or `STAGED_VALIDATED_WITH_CHALLENGES`. REWRITE must not commit the target project. SELF-CHECK remains available; only an explicit Operator cancellation or a technical/integrity failure stops further execution.
