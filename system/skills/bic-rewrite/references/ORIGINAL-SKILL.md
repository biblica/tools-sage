# REWRITE

Run `python scripts/bic.py rewrite --scope "<scope>"`. Complete the REWRITE pass in `workflow-system/current-unit/rewrite-pass.usfm`. Start SELF-CHECK only from the generated self-check brief; do not carry first-pass rationale. Write the corrected final file to `workflow-system/current-unit/self-check.usfm`, then run the printed commit command.

Follow `.clinerules/` and the protected rewrite-detail rules.
