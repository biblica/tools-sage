# Source authority and USFM

The routed SOURCE (`CONTENT_SOURCE`) is the exclusive authority for target content, meaning, ambiguity, discourse, source-significant capitalization, and human-readable marker payloads. DONOR (`LEXICAL_DONOR`) evidence is vocabulary-only. Pre-existing TARGET Scripture and original-language Scripture are not INSPECT inputs.

Use only the exact SOURCE scope and the governed task reads classified for their declared purpose. SOURCE content is `AUTHORIZED_CONTENT_EVIDENCE`; DONOR vocabulary is `AUTHORIZED_LEXICAL_EVIDENCE`; semantic packets are `PROJECT_INDEX_EVIDENCE`; VRS is `STRUCTURAL_EVIDENCE`; grammar is `LINGUISTIC_COMPETENCE_RULES`; Skill/schema material is `PROCESS_CONTROL`. No other file becomes content authority merely because it is listed. No unrouted translation, reference version, Greek/Hebrew text, or TARGET content is authorized.

Preserve protected semantic USFM structure and exact bounded coordinate coverage when describing structural challenges. INSPECT does not rewrite Scripture and therefore does not apply REWRITE-only protected output contracts.
